Ultrawide Fog Tint Fix

On an ultrawide screen CK3's distance fog washes out the sides of the map, and the left side gets an extra warm tint on top of it: the same bay is brown on the left of your screen and blue on the right, and northern conifers go almost white while the identical trees in the centre look normal.

This mod removes it. Ordinary map colours, ordinary water, all the way across.

WHY IT HAPPENS ON WIDE SCREENS

The fog factor in jomini_fog.fxh is built from this:

HorizFac = 1 - abs( normalize( CameraPosition - WorldSpacePos ).y )

Looking down at the middle of the screen, the vector from camera to terrain is mostly vertical, so that factor is near zero and there is no fog. Towards the left and right edges it becomes nearly horizontal and the factor approaches one. Fog is, in effect, "the edges of the screen" - and a 32:9 screen is mostly edges.

Then every distance in the formula is tuned for how far a 16:9 screen reaches. fog_end = 500 sets where the ramp saturates; a 32:9 screen sees roughly twice as far sideways, so its outer thirds sit at the cap permanently.

On top of that sits a second, asymmetric layer:

relative_fog_color = { 0.6 0.2 -0.2 }
relative_fog_begin = 100.0
relative_fog_end   = 400.0

Its blend factor depends only on how far left of the camera a pixel is, over a 500 unit window. It adds red and green and subtracts blue. On 16:9 that window is about as wide as the visible map and reads as a gentle atmospheric gradient; on 32:9 everything past 400 units to the left takes the full warm wash.

WHAT THE MOD CHANGES

Five environment files in gfx/map/environment/ - the ones that ship a non-zero relative fog - with the fog values replaced. As published it uses the off preset:

- fog_max = 0.0 - the distance fog ramp is zeroed, so nothing is blended anywhere
- relative_fog_color = { 0 0 0 } - the asymmetric warm layer is gone

No shader is touched, so there is no shader recompile and no first-load delay. Toggling the mod in the launcher playset is a clean A/B test against vanilla.

OTHER PRESETS

The source repository ships a small script with five presets, in case you want haze back but tuned for your screen instead of removed:

- vanilla - byte-identical to the base game, for comparison
- scaled - every distance doubled for 32:9 / 16:9 = 2, so a given screen position gets the haze a 16:9 player sees there, warm tint kept
- neutral - as scaled, minus the asymmetric warm tint
- soft - as neutral, with the strength cap cut from 20% to 8%
- off - what this item ships

NOTES

- On 16:9 this still works, it is just a much smaller change - the effect it removes is mild at that aspect ratio
- Graphics data only: no gameplay, script or history files are touched, so ironman and achievements are unaffected
- Safe to add or remove at any time, including mid-campaign
- Removing all distance fog does flatten the sense of depth on very distant mountains. If that bothers you, the soft preset from the repository is the one to use
- Built for CK3 1.19.x. These are full file overrides, so a patch that reworks the map environment will need an update here

COMPATIBILITY

Replaces five files in gfx/map/environment/. Conflicts only with mods that edit the same files - map graphics or lighting overhauls. If you use one, place this mod below it in the load order to keep the fix.
